# Suggested GenLayer Project Contribution

## Title

ProofSignal — Consensus-Based Crypto Claim Verification on GenLayer

## Description

ProofSignal is a crypto claim-verification application powered by GenLayer Intelligent Contracts. Users submit a claim together with a source URL, and the application retrieves and evaluates the source using GenLayer's AI-validator consensus. The contract produces a consensus-backed verdict — VERIFIED, FALSE, or UNCLEAR — together with an evidence summary, source reference, and timestamp.

The project addresses a real problem in crypto: announcements, testnet claims, airdrop requirements, listings, and token information are often scattered across unstructured web pages. GenLayer is central to the workflow because the application requires live web retrieval, natural-language interpretation, and decentralized adjudication rather than a deterministic database or a single centralized AI provider.
